## What is this project?
This project is about making a web-based EU4 game reviewer where a user can upload their savegame and have a summary/review of their game.

---

## Why am I making this?
I really like the game and want to contribute to the community with a free reviewer and also gain some experience on user-focused projects.

---

## Limitations
I implemented a plaintext parser. So the parsing is only supported for Normal mode (Non-Ironman). This will be a to-do later on, but not in the direct requirements of an MVP. It will be the top priority after I get a working version though.
